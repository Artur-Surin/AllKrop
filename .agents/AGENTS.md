# Project Rules Integration — All Kropyvnytskiy

Перед виконанням будь-якої задачі в цьому проєкті обов'язково дотримуйся вимог та регламенту з файлу [Rules.md](file:///Y:/laragon/www/newAllKropLaravel/Rules.md):

1. **Обов'язковий аналіз правил перед задачею**:
   - Перед наданням відповіді чи написанням коду звіряйся з [Rules.md](file:///Y:/laragon/www/newAllKropLaravel/Rules.md).
   - Працюй лише з існуючим функціоналом (без створення нових великих розділів/меню, якщо це прямо не вказано).
   - Переконайся, що кожна пропозиція відповідає щонайменше одному з 9 критеріїв цінності (UX, SEO, швидкодія, структура коду, архітектура Laravel, зручність користування, час на сайті, перегляди сторінок, монетизація).

2. **Обов'язкова структура відповіді**:
   Для кожної задачі спочатку спочатку надай:
   - **Аналіз** та можливі варіанти реалізації.
   - **Аргументацію найкращого рішення** (з позиції Senior Laravel Developer).
   - **Оптимізації та можливі покращення** (SEO, UX, Швидкодія, Монетизація).

3. **Стек та принципи**:
   - Стек: Laravel 11, PHP 8.4, MySQL, Redis, Livewire, Filament v5, Tailwind CSS, Alpine.js.
   - Дотримуйся SOLID, DRY, KISS. Застосовуй зважений підхід без надмірного over-engineering.
